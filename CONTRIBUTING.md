# Contributing

The map gets better every time someone fixes a row. Teams, users and researchers are all welcome.

## Correct a row or add a project

1. Open a [claim and correct issue](https://github.com/privacy-maxi/privacy-maxi.github.io/issues/new?template=claim-and-correct.yml).
2. Name the project, the field, the correct value and a source link.
3. You get a public answer within 48 hours.

One fact per issue keeps review fast. For a missing project, pick "new project" as the field and give its site,
code and what it hides.

## What counts as a source

Code, chain data, or a dated page: a commit, a contract address, a release, the project's own docs or notice, a
court or regulator record. Every fact in the data points to one.

## The rules

- **Projects bring facts; we keep the rating.** Tiers follow [METHOD.md](METHOD.md). Show a fact that meets a
  tier's definition and the tier moves with it.
- **Rate mechanisms, not people.** Corrections and comments stay on what the system does.
- **Everything happens in public.** Merged corrections are logged and the contributor is credited.

## Pull requests

Pull requests to the data are welcome. Edit the row, put the source in its `sources` list, and link the issue.
Pull requests to the site code are welcome too; open an issue first for anything large.
